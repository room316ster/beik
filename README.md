# ระบบเบิกจ่ายพัสดุและวัสดุ (Material Requisition System)

ระบบบริหารจัดการใบเบิกพัสดุ/วัสดุ ใช้งานฐานข้อมูล Google Sheets และหน้าเว็บ Frontend พร้อมสำหรับโฮสต์บน **GitHub Pages** มีระบบสั่งพิมพ์แบบฟอร์มใบเบิกพัสดุเป็น **A4 หน้าเดียว** ตามมาตรฐาน พร้อมช่องระบุ **จำนวนที่ขอเบิก** และ **จำนวนที่จ่ายจริง** ได้อย่างสะดวก

## 🌟 ฟังก์ชันเด่นของระบบ (ถอดแบบจากเอกสารจริง 100%)

1. **หน้าตาและโครงสร้างตาราง 3 คอลัมน์ 143 รายการ แบบเดียวกับภาพต้นฉบับ**:
   - **คอลัมน์ที่ 1**: รายการที่ 1 - 50 (กระดาษ, กาว, คลิปดำ, เครื่องเจาะ/เย็บ, ซองครุฑ, เทป ฯลฯ)
   - **คอลัมน์ที่ 2**: รายการที่ 51 - 100 (ใบมีดคัตเตอร์, ปากกา, แฟ้ม, สมุด, สติกเกอร์, หมึกเติม ฯลฯ)
   - **คอลัมน์ที่ 3**: รายการที่ 101 - 143 (หมึกเลเซอร์ HP, Xerox, Brother, Canon, ผ้าหมึก, ถ่านไฟฉาย ฯลฯ)
   - มีเส้นแบ่งแนวตั้งสีเหลืองทองระหว่างคอลัมน์เหมือนเอกสารตัวอย่างจริง
   - บล็อกลงลายมือชื่อ 3 ตำแหน่งอยู่ด้านล่างคอลัมน์ที่ 3 (ผู้เบิก/หัวหน้ากลุ่ม, ผู้อนุมัติ/หัวหน้าหน่วยงาน, ผู้จ่าย/เจ้าหน้าที่พัสดุ)

2. **กรอก "จำนวนที่เบิก" และ "จำนวนที่จ่าย" ได้โดยตรงในทุกแถว**:
   - พิมพ์ตัวเลขลงในช่อง **เบิก** ได้ทันที โดยระบบจะช่วยเติมช่อง **จ่าย** ให้เท่ากันอัตโนมัติ (สามารถแก้ไขจำนวนจ่ายได้อย่างอิสระ)
   - แถวที่มีการระบุจำนวนจะเปลี่ยนเป็นสีเหลืองอ่อนไฮไลต์ให้เห็นชัดเจนทันที
   - แถบเมนูด้านบนแสดงยอดรวม: จำนวนรายการที่เลือก, ยอดเบิกทั้งหมด, ยอดจ่ายทั้งหมด

3. **สั่งพิมพ์เป็น A4 หน้าเดียว (Single Page A4 Guaranteed)**:
   - ใช้ CSS Print `@page { size: A4 portrait; margin: 3mm 4.5mm 2.5mm 4.5mm; }`
   - เมื่อกดปุ่ม **"พิมพ์ A4 หน้าเดียว"** ระบบจะแปลงช่องกรอกเป็นข้อความเรียบร้อยและสั่งพิมพ์ทั้ง 143 รายการพร้อมลายมือชื่อออกมาใน **กระดาษ A4 หน้าเดียวพอดี ไม่ล้นไปหน้าที่ 2**

4. **ปุ่มอำนวยความสะดวกบนแถบเครื่องมือ**:
   - 🔍 **ค้นหาด่วน**: พิมพ์ชื่อพัสดุ (เช่น "A4", "คลิป", "หมึก", "ปากกา") ตารางจะเลื่อนและไฮไลต์แถวที่ตรงกันทันที
   - ⚡ **จ่าย = เบิก**: คัดลอกจำนวนเบิกทั้งหมดไปเป็นจำนวนจ่ายในคลิกเดียว
   - 👁️ **เฉพาะที่เบิก**: สลับแสดงเฉพาะแถวที่มีตัวเลขเบิก หรือแสดงทั้งหมด 143 รายการ
   - 💾 **บันทึกชีต**: บันทึกข้อมูลใบเบิกและรายการพัสดุที่มีการเบิกลง Google Sheets ทันที
   - 📜 **ประวัติ**: ดูประวัติใบเบิกย้อนหลัง พร้อมปุ่มโหลดข้อมูลเดิมกลับมาพิมพ์ซ้ำได้ตลอดเวลา

## 📁 โครงสร้างไฟล์ในโปรเจกต์

```text
├── index.html        # หน้าเว็บหลัก Web App (ฟอร์มเบิก, ประวัติ, คลังวัสดุ, A4 Print Area)
├── style.css         # สไตล์การแสดงผล และกฎการพิมพ์ A4 (@media print)
├── app.js            # ตรรกะการทำงาน ฝั่ง Client, การคำนวณ, การพิมพ์ และการเชื่อมต่อ API
├── รหัส.js           # โค้ด Google Apps Script Backend (API สำหรับจัดการ Google Sheets)
├── appsscript.json   # ไฟล์ Manifest ตั้งค่า Apps Script และสิทธิ์ OAuth
├── .clasp.json       # ไฟล์ตั้งค่า Clasp สำหรับการ Push โค้ด
└── README.md         # คู่มือการใช้งานและการติดตั้ง
```

## 🚀 วิธีการ Push โค้ดขึ้น Google Apps Script (Clasp)

โปรเจกต์นี้ตั้งค่า `.clasp.json` ไว้เรียบร้อยแล้ว หากมีการแก้ไขโค้ด `รหัส.js` สามารถรันคำสั่ง:

```bash
# ส่งโค้ดขึ้น Apps Script
npx @google/clasp push -f

# สร้าง Deployment ใหม่
npx @google/clasp deploy --description "Material Requisition Update"
```

## 🔑 ขั้นตอนการอนุญาตสิทธิ์ Apps Script (Authorize Access) ครั้งแรก

เนื่องจาก Google Apps Script มีการเข้าถึง Google Sheets ผู้ดูแลระบบต้องกดอนุญาตสิทธิ์ 1 ครั้ง ดังนี้:

1. เปิดเบราว์เซอร์ไปที่: [Google Apps Script Editor](https://script.google.com/d/1jWaOODlUB_v66S_yuHD4SAsbFlH0R6Jg9hsvQ8Psg_5smFJI5VpB92Ba/edit)
2. ที่แถบเมนูฟังก์ชันด้านบน ให้เลือกฟังก์ชัน `setupDatabase` แล้วคลิก **"เรียกใช้" (Run)**
3. จะมีหน้าต่างป๊อปอัปแจ้งเตือนสิทธิ์ ให้คลิก **"ตรวจสอบสิทธิ์" (Review permissions)**
4. เลือกบัญชี Google ของท่าน
5. หากพบหน้าเตือน "Google ยังไม่ได้ยืนยันแอปนี้" ให้คลิก **"ขั้นสูง" (Advanced)** แล้วคลิก **"ไปที่... (ไม่ปลอดภัย)"**
6. คลิก **"อนุญาต" (Allow)**
7. ระบบจะสร้างชีต `วัสดุ`, `ใบเบิกวัสดุ`, `รายการเบิกย่อย`, และ `ตั้งค่า` ลงใน Google Sheet ให้อัตโนมัติทันที

## 🌐 ขั้นตอนการนำหน้าเว็บขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน [GitHub.com](https://github.com) (เช่น ชื่อ `material-requisition-app`)
2. เปิด Terminal ในโฟลเดอร์ `d:\appscript\ใบเบิกวัสดุ` แล้วพิมพ์คำสั่ง:
   ```bash
   git init
   git add .
   git commit -m "feat: ระบบเบิกจ่ายวัสดุพร้อมสั่งพิมพ์ A4 หน้าเดียว"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/material-requisition-app.git
   git push -u origin main
   ```
3. ในหน้า GitHub Repository:
   - ไปที่แท็บ **Settings** > เมนูด้านซ้ายเลือก **Pages**
   - ในหัวข้อ **Build and deployment** > Source ให้เลือก **Deploy from a branch**
   - Branch: เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. ภายใน 1-2 นาที คุณจะได้รับลิงก์เว็บ เช่น `https://<YOUR_GITHUB_USERNAME>.github.io/material-requisition-app/` ใช้งานได้ทันทีทั่วโลก!
